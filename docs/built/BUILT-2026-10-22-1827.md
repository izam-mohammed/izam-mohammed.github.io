## In short

The owner's personal website at https://izam-mohammed.github.io/: plain
HTML in browser-default looks, a little vanilla JavaScript, no framework,
no build and no npm (`CLAUDE.md`). A home page and a set of "brain dump"
pages (lists, ideas, links, a changelog). Opened locally by opening
`index.html`; published by GitHub Pages on every push to `main`.

## What a person can use

### The home page

- The intro page with a visit counter, a "spy box" that shows the
  visitor's IP, rough location and weather from public APIs, and a
  source-code reveal (`index.html`, `assets/js/home.js`; PR `#2`).
- An hourly "what am i doin'" status, stored rot13-encoded
  (`assets/js/what-am-i-doin.js`).
- Console easter eggs for anyone opening devtools (`assets/js/hey-dev.js`).
- A custom 404 page (`404.html`).

### Brain dumps

- An index and 14 pages: bucket list, software ideas (shower thoughts,
  with the built ones marked, PR `#8`), things to learn, cognitive biases,
  blogs, links, doomscroll sites, AI tools, movies, rebuild-from-scratch
  projects, life lessons, FAQ, projects, and a commit changelog
  (`brain-dumps/*/index.html`; PRs `#2`, `#6`, `#8`).
- Long lists fold behind a "see more" button and deep links unfold and
  highlight their item; an opt-in paper theme sits behind a toggle
  (`assets/js/common.js`, `assets/css/theme.css`; PR `#7`).
- Emails obfuscated with rot13 and decoded in the page
  (`assets/js/common.js`).

### For crawlers

- `sitemap.xml`, `robots.txt`, `llms.txt` and a joke `openapi.json`,
  generated from the pages by `scripts/gen-meta.py` (commit `d0d230e`).

### Reading the repository

- A plain-text README with a heading; a banner is open in PR `#9`
  (`feat/readme-banner`), not merged.

## Under the hood

- **Shape**: static files only; shared behaviour in `assets/js/common.js`
  loaded by relative path from every page (`CLAUDE.md`).
- **Data**: `assets/data/tz-aliases.json`; no backend, no database.
- **Integrations**: browser calls to api.ipify.org, api64.ipify.org,
  ipapi.co and api.open-meteo.com (`assets/js/home.js`), allowed by the
  CSP in `_headers` and `vercel.json`.
- **Deploy**: `.github/workflows/static.yml` copies the paths in
  `.deployinclude` into `_site` and deploys it with `actions/deploy-pages`
  on push to `main`. The repository's Pages source is set to "deploy from
  a branch" (`main`, `/`; `gh api repos/.../pages` reports `build_type`
  `legacy`), and `pages-build-deployment` runs too. `vercel.json` and
  `.vercelignore` exist for a Vercel deploy (commit `73be6d4`); whether a
  Vercel project is live is unverified.
- **Standards and CI**: `.github/workflows/vibe-check.yml` (no Tailwind,
  no `node_modules`, every HTML page's top folder in `.deployinclude`) on
  push to `main` and by hand, not on pull requests.
  `.github/workflows/security.yml` calls the shared gate at `ff76c48` with
  `ecosystem: node` on PRs and weekly. `.pre-commit-config.yaml` holds
  gitleaks and the standard hooks; `.githooks/pre-commit` logs commits to
  the changelog and reruns `scripts/gen-meta.py`. No local check command,
  no `docs/standards.md` before this snapshot's commit. The `Makefile`
  targets are jokes (`make cry`).

## Unfinished or broken

- `.deployinclude` does not limit what is public: with the Pages source on
  "deploy from a branch", the whole repository is served.
  https://izam-mohammed.github.io/CLAUDE.md, `/.env`, `/Makefile` and
  `/scripts/gen-meta.py` all answered HTTP 200 on 22/10/2026. The tracked
  `.env` holds only joke values (commit `208b3c9`, its own comments say
  so), so nothing secret is exposed, but the filter is not doing its job.
- `vibe-check.yml` runs after merge, not on the pull request.
- `static.yml` and `vibe-check.yml` pin actions by tag (`@v7`, `@v6`,
  `@v5`), not by commit SHA as the shared `.github` conventions ask.
- No HTML validation, link check, JavaScript lint, or Python lint or tests
  for `scripts/gen-meta.py`.
- The generated metadata is fresh at `b2d2bef` (`gen-meta.py` rerun in a
  scratch copy produced identical files), but only the local hook keeps it
  so; CI does not check it.
- README banner: in flight in PR `#9`; not re-planned here.
- Not applicable here, by judgement: a `site/` one-pager (the repository
  is the site) and a 90 % coverage floor over the browser JavaScript
  (DOM-bound IIFEs, and `CLAUDE.md` rules out npm and a test harness);
  the floor does apply to `scripts/gen-meta.py`, the one piece of program
  logic, in `plans/01-quality-gates.md`.
